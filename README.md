# MDRRMO API

Starter repository structure for the MDRRMO incident reporting API. The PHP files are placeholders for the incident endpoints and PostgreSQL connection.

```text
mdrrmo-api/
├── public/api/incidents/
│   ├── create.php
│   ├── list.php
│   └── view.php
├── src/
│   ├── database.php
│   └── db_connection.php
├── .dockerignore
├── .gitignore
├── README.md
└── test-db.php
```
